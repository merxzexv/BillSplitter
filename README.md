<h1 align="center">Bill Splitter</h1>

Single-file web application to track shared expenses and compute minimal debt settlements. Zero dependencies, runs directly in any browser.

## Features

Supports adding group members, splitting expenses equally or by exact amounts, and settling debts in at most $N - 1$ transactions. Includes an itemized expense history and one-click clipboard export.

## Usage

1. Open `index.html` in any web browser or visit [mybillsplit.vercel.app](https://mybillsplit.vercel.app/)
2. Add group members in the Members panel.
3. Enter expense details, select the payer, and choose equal or exact splits.
4. Review the auto-generated settlements and copy summaries to the clipboard.

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6+)
- Inter font, Phosphor Icons (via CDN)
